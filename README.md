# Master of Darkness Recomp

Port nativo de *Master of Darkness* (Sega Master System, 1992) para Android y PC, con opciones modernas (16:9, filtros, mejoras gráficas).

**Este repositorio no contiene la ROM.** Cada usuario debe aportar su propia copia legal:
`Master of Darkness (Europe, Brazil) (En).sms` — CRC32 `96FB4D4B`.

Estado: fase 1 (análisis) completada — ver `docs/NOTAS_TECNICAS.md`.
